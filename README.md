# Шәкірт

**AI жауап бермейді. Ол қателеседі — ал сен оны түзетесің.**

Шәкірт — ондық бөлшектерді үйренуге арналған веб-қосымша. Жасанды оқушы Ерлан есепті қате ережемен шығарады. Оқушы оның қатесін табады, сенімділігіне бәс тігеді, ережесін анықтайды және түзетеді. Түзету бес жасырын есепте автоматты түрде тексеріледі, ал «Айна» беті оқушының өз жаңылыс түсініктерін Байес моделімен бағалайды.

- **Сайт және қосымша:** https://yersultan2000.github.io/shakirt/
- **Күйі:** прототип. Нақты оқушылармен әлі сыналған жоқ, оқу нәтижесіне әсері өлшенген жоқ.

> **Кратко по-русски.** Веб-приложение для 5–8 классов: ученик не получает ответ от AI, а исправляет искусственного ученика Ерлана, который ошибается по устойчивому неверному правилу. Работает целиком в браузере, без интернета, API-ключей и регистрации.

## Құрылымы

```
index.html              сайт + қосымша (бір файл, ~190 КБ, қаріптерімен бірге)
src/site/               сайттың бастапқы коды
  engine.js             ережелер қозғалтқышы және оқушы моделі
  site.js               интерфейс: лендинг, сабақ, басты бет, Айна, маршрут
  site.css              дизайн-токендер, жарық және қараңғы тақырып, mobile-first
  site.body.html        бет құрылымы
  fonts.css             Inter және моноширинді қаріптің ішкі жиыны (woff2)
  build_site.py         бәрін бір index.html файлына жинайды
tests/test_site.py      Playwright арқылы браузерлік тест
```

## Іске қосу

Сайт: `index.html` файлын кез келген браузерде ашыңыз. Сервер керек емес.

Өзгерістен кейін қайта жинау:

```bash
python3 src/site/build_site.py      # → index.html
```

Тест:

```bash
pip install playwright && playwright install chromium
python3 tests/test_site.py
```

Тест 12 раундты басынан аяғына дейін ойнайды (қате ереже ұсынылған жағдайды қоса), кітапхана сүзгісін, модаль терезені, тақырып ауыстыруды, мобильді экранда көлденең айналудың жоқтығын және консоль қателерінің жоқтығын тексереді. Қозғалтқыш бөлек тексерілді: 8 жаңылыс ереже × 300 кездейсоқ есеп = 2 400 тексеріс, бірде-бір жаңылыс ереже жасырын сынақтан өтпейді, дұрыс ережелер әрқашан өтеді.

## Сайт мүмкіндіктері

| Бөлім | Не істейді |
|---|---|
| Hero | Тірі мысал: Ерланның жауабын бағалап, бәс тігуге болады, сегіз қате түрі кезекпен шығады |
| Қалай жұмыс істейді | Төрт қадамның интерактивті көрінісі, экранда тұрғанда өзі ауысады |
| Айырмашылық | Кәдімгі AI-көмекші мен Шәкірттегі диалог қатар |
| Қателер кітапханасы | Тақырып бойынша сүзгі; әр ереже модаль терезеде жаңа мысалдармен ашылады, сол қатемен раунд бастауға болады |
| Айна | Оқушының жаңылыс түсініктер бағасы (нақты деректен) |
| Қосымша | Сабақ (4 қадам), басты бет (калибрлеу қисығы, BKT, тарих), Айна, деректерді өшіру |

Жарық және қараңғы тақырып (жүйеге қарай немесе қолмен), `prefers-reduced-motion` қолдауы, пернетақтамен басқару, модаль терезеде фокус ұстау. Деректер тек құрылғыдағы `localStorage`-та сақталады.

## Алгоритмдер

- **Ережелер.** 4 тақырып, 4 дұрыс және 8 жаңылыс ереже — әрқайсысы орындалатын функция. Ондық сандар бүтін сандармен есептеледі, float қатесі жоқ.
- **Айна.** Әр жаңылыс түсінік үшін P(m), бастапқы мәні 0.2. Қате жауапты қабылдау ықтималдығы: 0.85 (түсінік бар) және 0.15 (жоқ), сенімділікпен салмақталады: `w = 2·(бәс − 0.5)`.
- **Раунд таңдау.** Күтілетін ақпарат өсімі ең жоғары жаңылыс түсінік.
- **Шеберлік.** Bayesian Knowledge Tracing (L0 0.2, T 0.15, G 0.25, S 0.1).
- **Калибрлеу.** Brier ұпайы және бес аралықты калибрлеу қисығы.

Модель параметрлері — сарапшылық болжам, нақты дерекпен бағаланбаған.

## Ғылыми негіз және шектеулер

Еске түсіру практикасы (Adesope т.б., 2017, g = 0.51), аралас жаттығу (Brunmair & Richter, 2019, g = 0.42), теріске шығару мәтіні (Schroeder & Kucera, 2022, g = 0.41), өнімді сәтсіздік (Sinha & Kapur, 2021, g = 0.36), hypercorrection (Butterfield & Metcalfe, 2001), protégé effect (Chase т.б., 2009), BUGGY (Brown & Burton, 1978). Бұл — жеке әдістердің әсері, Шәкірттің әсері емес.

Шектеулер: бір сала (ондық бөлшектер), 8 жаңылыс ереже, түзету дайын карточкалардан таңдалады, интерфейс тек қазақ тілінде, мұғалім панелі жоқ.
