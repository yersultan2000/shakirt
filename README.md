# Шәкірт

**AI жауап бермейді. Ал сен оны түзетесің.**

Шәкірт — ондық бөлшектерді үйренуге арналған веб-қосымша. Жасанды оқушы Ерлан есепті қате ережемен шығарады. Оқушы оның қатесін белгілейді, сенімділігіне бәс тігеді, ережесін анықтайды және оны ауыстырғыштардан қайта құрастырады. Түзетілген ереже бес жасырын есепте шынымен орындалып тексеріледі, ал «Айна» оқушының өз жаңылыс түсініктерін Байес моделімен бағалайды.

- **Сайт және қосымша:** https://yersultan2000.github.io/shakirt/
- **Тілдер:** қазақ, орыс
- **Күйі:** прототип. Нақты оқушылармен әлі сыналған жоқ, оқу нәтижесіне әсері өлшенген жоқ.

> **По-русски.** Веб-приложение для 5–8 классов: ученик не получает ответ от ИИ, а исправляет искусственного ученика Ерлана, который ошибается по устойчивому неверному правилу. Работает в браузере, офлайн, без регистрации и API-ключей. Интерфейс на казахском и русском.

## Дизайн

Арт-бағыт — «тексерілген дәптер»: тордағы қағаз, қызыл жиек сызығы, үш «қол».

| Кім | Қалай көрінеді | Қаріп |
|---|---|---|
| Интерфейс | графит | Geist |
| Ерлан | көк сия, тордағы жазу | Geist Mono |
| Оқушы | қызыл қалам: дөңгелек, сызу, жазу | Caveat |

Қызыл түс тек оқушының белгісі мен құлаған тест үшін. Негізгі батырмалар — графит. Барлық қаріп қазақ әріптерін (Ә Ғ Қ Ң Ө Ұ Ү Һ І) толық қамтиды. Жарық және қараңғы тақырып, `prefers-reduced-motion` қолдауы.

## Мүмкіндіктер

**Сайт:** ойналатын дәптер (Ерланның жауабын белгілеп, бәс тігуге болады), 100 орынды сынып суреті, айналдырғанда өзгеретін жабысқақ дәптер («Қалай жұмыс істейді»), екі беттік салыстыру, сүзгісі бар қателер индексі және ереже терезесі, Айна мысалы, жиектегі ғылыми ескертпелер, мобильді мәзір.

**Сабақ (4 қадам):**
1. **Тексер** — «Дұрыс» / «Қате» және 50–100% сенімділік. Ұпай тиын лақтырумен салыстырылады: 50% бәс = 0, 100% дұрыс = +25, 100% қате = −75.
2. **Болжа** — Ерланның келесі жауабы. Заңдылық көрінетін жолдарды белгілеуге болады.
3. **Диагноз** — кеңес баспалдағы: қате таңдасаң, сол ереже түсіндірмейтін жол белгіленіп, оның не жазатыны көрсетіледі.
4. **Түзет** — ереже құрастырғыш: Ерланның ережесі ауыстырғыштар түрінде беріледі, оларды өзгерткенде жауабы бірден өзгереді. Жасырын сынақтың әр құлаған жолында дұрыс жауап жазылады.

**Басқасы:** раунд әр қадамнан кейін сақталады; басты бетте калибрлеу қисығы, тақырып бойынша шеберлік (BKT), тарих; Айна жолдары ереженің өзіне апарады; деректерді файлға сақтау және жүктеу; дыбыс әдепкіде өшірулі; пернетақта: `1`/`2` — Дұрыс/Қате, `←`/`→` — сенімділік, `1–5` — нұсқалар.

**Офлайн:** service worker барлық файлды кэштейді, сайтты телефонның басты экранына қосуға болады. Сілтеме бөліскенде Open Graph суреті шығады.

```

sw.js, manifest.webmanifest, icon-*.png, og.png

src/core.js           тіл, тақырып, мәзір, модаль, Ерланның 4 бет-әлпеті, дәптер, маршрут
src/landing.js        лендинг бөлімдері
src/app.js            сабақ, басты бет, Айна, пернетақта
src/site.css          дизайн-токендер және компоненттер
src/body.html         бет құрылымы (орысша мәтін — data-ru атрибуттарында)
```

## Іске қосу және тексеру

```bash
python3 -m http.server 8765            # http://localhost:8765
python3 build.py                       # src/ өзгергеннен кейін
node tests/test_engine.js              # «0 [] []» — қате жоқ
pip install playwright && playwright install chromium
python3 tests/test_site.py             # сервер іске қосулы болуы керек
```

Браузерлік тест: демо (кеңес, пернетақта, фокус), сүзгі, модаль, раундтың бетті қайта жүктегенде сақталуы, 11 толық раунд (қате диагноз және қате құрастыру жағдайларымен), тіл ауыстыру, 390 px жарық және қараңғы экранда мәзір мен көлденең айналудың жоқтығы, консоль қателерінің жоқтығы.

Қозғалтқыш тесті 1 500 рет: әр қате ереже өз есебінде қате, «кездейсоқ дұрыс» есепте дұрыс; ешбір қате ереже жасырын сынақтан өтпейді; құрастырғыштың дұрыс жиыны әрқашан өтеді, қалған жиындардың бәрі құлайды.

## Алгоритмдер

- **Айна.** Әр жаңылыс түсінік үшін P(m), бастапқысы 0.2. Қате жауапты қабылдау ықтималдығы 0.85 (түсінік бар) және 0.15 (жоқ), сенімділікпен салмақталады: `w = 2·(бәс − 0.5)`. Қате ережені құрастыру да сол ереже бойынша бағаны көтереді.
- **Раунд таңдау.** Күтілетін ақпарат өсімі ең жоғары жаңылыс түсінік.
- **Шеберлік.** Bayesian Knowledge Tracing (L0 0.2, T 0.15, G 0.25, S 0.1); ойналмаған тақырып «басталмаған» деп көрсетіледі.
- **Калибрлеу.** `100·(0.25 − (p − o)²)` — тиынмен салыстырғандағы дұрыс бағалау ережесі; Brier ұпайы және калибрлеу қисығы.

Модель параметрлері — сарапшылық болжам, нақты дерекпен бағаланбаған.
